# CodeLogicX documentation

CodeLogicX helps a team plan, build, review, deploy, and observe software from one workspace.

## Start here

Use the **Work** area to manage projects and delivery records. Use **Agents** when a project needs
planning, code changes, or review. Use **Deployment** to inspect the connected Hostinger VPS.

## Documentation format

Each article is an `.mdx` file inside the DevKit web module. MDX supports Markdown and React
components in the same document.

```mdx
# Project guide

Write the project instructions here.
```

Add the article to `docs.registry.ts` after you create the file.
