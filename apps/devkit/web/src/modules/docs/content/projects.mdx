# Projects

A Project is the main context for engineering work. It connects planning records, repositories,
tasks, Agent runs, releases, and deployment evidence.

## Create a Project

1. Open **Work → Projects**.
2. Select **New Project**.
3. Add the project name, owner, logo, and identification color.
4. Save the Project.
5. Open the Project and connect its repository.

## Cloud sync

Project sync sends Project records to `https://devkit.codexsun.com`. The first phase does not send
tasks, files, credentials, planning boards, or Agent history.

Open **Cloud → Project Sync** to verify both installations before a manual upload.
